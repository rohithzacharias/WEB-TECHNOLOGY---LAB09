# Experiment 09 – Form Validation and Routing Using AngularJS

## Description
This experiment demonstrates form validation and page routing using AngularJS in a TechZone Electronics Store webpage. It includes a customer registration form with validation for name, password, age, mobile number, email, gender, and state. AngularJS routing is implemented to navigate between Home, Products, Register, and Contact pages without reloading the entire application.

## Objectives
- To implement form validation using AngularJS.
- To validate user input fields based on specified conditions.
- To display error messages for invalid inputs.
- To enable form submission only when all fields are valid.
- To implement page navigation using the AngularJS ngRoute module.

## Validation Features
- Name should contain only alphabets and spaces.
- Password must contain at least 8 characters, one uppercase letter, one lowercase letter, and one number.
- Age must be between 18 and 30.
- Mobile number must contain exactly 10 digits.
- Email must be in a valid format.
- Gender and state selection are mandatory.
- Submit button is enabled only when all fields are valid.
